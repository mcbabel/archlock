# Roadmap

- `archlock audit`: let your agent review the soft invariants against the code (warnings only).
- Typed extraction beyond TypeScript files: component scripts (`.vue`, `.svelte`, `.astro`) and other languages' type information.
- More languages (Kotlin, Swift, PHP, …): the extractor interface is small
  ([CONTRIBUTING.md](../CONTRIBUTING.md#adding-a-language)).
- Finer cycle rules (allowed cycles, layers).
